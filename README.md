# Task 5 - Deploy a Static Website Using GitHub Pages

## Objective

The objective of this task is to create and deploy a static website using GitHub Pages for free.

## Project Description

This project is a simple responsive portfolio website created using HTML, CSS, and JavaScript.

The website is hosted using GitHub Pages.

## Technologies Used

* HTML
* CSS
* JavaScript
* Git
* GitHub
* GitHub Pages

## Project Files

* `index.html` - Main structure of the website
* `style.css` - Styling and responsive design
* `script.js` - JavaScript interactivity

## Features

* Responsive navigation bar
* Home section
* About section
* Skills section
* Projects section
* Contact section
* Interactive JavaScript buttons
* Responsive design
* Free deployment using GitHub Pages

## Deployment Process

1. Created a GitHub repository.
2. Created a static website using HTML, CSS, and JavaScript.
3. Used Git to track the project files.
4. Pushed the project to GitHub.
5. Enabled GitHub Pages.
6. Deployed the website using the `main` branch.

## Learning Outcomes

Through this task, I learned:

* What Git is and why version control is important.
* How to initialize a Git repository.
* How to add and commit files.
* How to push a project to GitHub.
* How GitHub Pages hosts static websites.
* The difference between static and dynamic websites.
* Basic continuous deployment concepts.
